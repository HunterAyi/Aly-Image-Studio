# Aly Image Studio

免费使用的本地 AI 图片创作软件。作者 **ayi** · [Aly 官方入口](https://www.aly18.com)。

**最新正式版：v0.29.0 · Windows 10 22H2 / Windows 11 x64**

**[① 下载 ZIP（推荐）](https://github.com/HunterAyi/Aly-Image-Studio/releases/download/v0.29.0/AlyImageStudio-0.29.0-Windows-x64.zip)** · **[② 直接下载安装程序](https://github.com/HunterAyi/Aly-Image-Studio/releases/download/v0.29.0/AlyImageStudio-0.29.0.1-stable-Setup.exe)**

ZIP 仅包含安装程序、使用说明.txt、隐私说明.txt。解压后安装，通过已有的 Edge / Chrome 使用，无需安装 Python、Office 或 FFmpeg。

1. 安装后双击桌面 Aly Image Studio，打开本机工作台。
2. 在 API 设置中添加服务商 KEY，拉取并选择图片模型。
3. 输入提示词，按需要添加参考图和调整参数，提交生成。

## v0.29.0 更新

- **API 设置重新整理**：模型卡片与模型能力、资料来源分区显示；连接和 KEY 的新增、修改使用居中窗口。已识别图片型号按模型基底映射，无需手选协议；未知型号保留等待对接，原始模型 ID 保持。
- **模型选择和工作台统一外观**：彩色图标与 KEY 分组、居中模型卡片、清晰的选中底色；卡片不再重复显示参数。保留浅色、暗色和个人主题，修复启动时旧绿色背景闪现。
- **补齐 OpenAI 2.6 图片适配**：按模型能力提供尺寸、复杂度与 GIF 等参数，保留图片原件；实际可用能力仍取决于所选服务商。
- **GIF 单帧预览**：右侧单列帧栏独立滚动，点击某帧暂停查看，点击栏外或失焦恢复播放。
- **参考图显示开关**：近期任务与历史图库分别记住显示偏好，开关名称悬停可见；参考图的上传、选用和原始记录继续保留。
- **顶栏联系作者**：点击打开作者资料。移除本轮 AI 对话和聊天连接界面，旧本机资料保留；生图器继续作为独立软件使用。
- **托盘组件隔离**：保留托盘操作和组件合法替换能力，改由独立辅助进程运行；任务保活、重复启动与正常退出继续可用。

## 日常创作

支持文生图、参考图编辑、每批 1–4 个独立任务，以及近期任务、历史图库、原图预览、重命名、复制原图和另存为。参考图可拖动排序；自由模式识别明确的尺寸和比例，按当前模型能力转换并提前提示冲突。生成超时或结果未知不自动重复收费请求，保存失败可仅重试下载。

生图器和 Aly 画布独立。本版不提供 AI 对话界面；旧聊天资料仍保存在本机。

## 老用户更新

已安装用户在系统设置中检查更新，下载校验后确认安装。程序正常退出后，会在**原安装文件夹**更新并重启，无需重新选择文件夹。KEY、设置、历史、草稿和作品保留。首次安装请选择 ZIP 或安装程序；`update-stable.json` 与 `.sig` 由软件读取。

资料默认位于 `%LOCALAPPDATA%\AlyImageStudio`。KEY 由当前 Windows 用户加密保存，换电脑或用户可能需要重新输入；默认卸载保留个人资料和外部原图，请备份重要作品。
