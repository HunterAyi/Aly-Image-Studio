# Aly Image Studio 安装与使用

版本：0.27.5。作者：ayi。官方入口：https://www.aly18.com

## 安装和启动

目标平台为 Windows 10 22H2 / Windows 11 x64；已验证范围见 GitHub 发布页的《版本与验证说明》。压缩包仅含安装程序、使用说明.txt、隐私说明.txt。解压后双击 Setup.exe，阅读许可后安装。必要的程序许可、第三方通知及对应源码说明随程序安装；开始菜单可打开“第三方许可说明”。优先仅为当前 Windows 用户安装，使用已有 Edge/Chrome，无需安装 Python、Office 或 FFmpeg；软件不会自动安装浏览器或下载运行依赖。安装和本机启动可以离线完成，模型服务需要联网。

从桌面快捷方式启动，通过浏览器访问本机工作台。托盘提供重新打开、日志、资料文件夹和退出入口。默认关闭最后一个工作台页面约30秒且没有活动任务后退出；活动任务期间保持后台服务。重复启动会复用本通道正在运行的实例。

没有购买 Windows 代码签名证书，Windows 可能显示“未知发布者”或 SmartScreen 提示。请核对来源及官方 SHA-256，不要关闭安全防护或添加排除项。资源自有签名用于检测页面等文件被修改，不是 Windows 可信代码签名，不能保证防篡改不可绕过。

## KEY 和费用

软件免费，无软件账号登录。需要模型服务时，向你选择的服务商申请 KEY 并了解费用。内置 Aly 入口，同时支持自行配置的其他平台；生图和聊天的地址、KEY、模型和设置完全独立。填写 KEY 后保存，拉取并选择模型。KEY 默认使用当前 Windows 用户加密保存，换用户/换电脑不能直接保证可用，迁移后需重新输入。

模型列表成功不代表生成已验证。未知型号能力需要按渠道资料设置。生成和聊天可能收费，超时/结果未知时不要重复提交；软件不会自动重试收费 POST。普通聊天一轮一次请求，创作助手的连续步骤受会话权限及限额控制。

## 图片、聊天和文件

填写提示词、选择支持的参数，按需加入参考图，再生成。每批1–4张独立任务，默认1张。工作图归档到资料目录 output/日期；查看器缩放不修改原图。图库可关联本机图片；解除关联保留原文件，原文件移动或修改后关联可能失效。

主预览和放大窗口先显示缩略图及轻量预览，放大到细节时加载完整原图；预览信息中的 M 表示原文件大小。参考图、另存为和复制原图使用原文件，预览优化不改变作品。未明确选择质量时，默认使用当前模型支持的最高档；已有质量选择保留。内置生图请求地址为 https://img.aly18.com，聊天和其他平台独立。新配置默认超时500秒，旧配置保留原值，可在高级设置中修改并保存。

AI对话支持适用模型的图片、文件及多模态输入；原生能力取决于模型和平台协议。普通视觉模型使用视频抽帧，不含音频，不能等同完整视频理解。回复结束不代表模型已成功完成本地工具成果；请检查任务状态和实际文件。

另存为通过本机目录选择器授权；副本不会随着图库删除自动删除。外部原图改名会修改原位置文件，需要确认。请自行保管重要作品备份。

## 资料、升级与卸载

正式通道资料默认位于 `%LOCALAPPDATA%\AlyImageStudio`，内部测试通道为 `%LOCALAPPDATA%\AlyImageStudioTest`；数据库、KEY密文、日志、附件位于 data，图片位于 output。测试和正式资料不混用。开发版兼容原项目目录，不自动搬动旧资料。

正式版启动后会检查官方新版；有更新时顶部提示，也可从系统设置点击“检查更新”。先点“下载新版”，下载完成并通过官方签名与文件校验后，点“确认退出并安装”。有任务或文件操作进行时暂不能安装，请先完成或停止。软件正常退出后，将新版完整程序及依赖安装到原来的安装目录，并重新启动；KEY、设置、历史和作品保留。内部版本目录用于防止升级中断后混装，新版启动验证通过、旧程序及更新助手退出后自动清理能核对为官方原文件的旧版本和更新包。用户新增或修改的旧目录文件、未知来源目录一律保留，不清理个人资料。

更新窗口显示下载大小和预计临时占用，下载前检查缓存盘与安装盘空间；完整程序更新仍需短时同时容纳新旧版本。新版下载与安装临时文件优先放在原安装盘 .aly-updates，已下载且校验通过的同一安装包可复用。由旧版发起的本次升级仍可能使用旧缓存位置，新版随后清理可确认的过期安装包。

如果任务显示“生成成功，保存失败”，上游结果已保留，请在任务记录中点击“仅重试下载”，不要再次生成以免重复扣费。新版图片下载兼容 Windows 手动系统代理和 VPN 虚拟 DNS，保持公网地址与HTTPS检查；结果链接可能过期，过期后需要联系上游取回原结果或新下载链接。

系统设置中的“GitHub 官方下载”可直接打开正式发布页。开发版可手动检查正式版本、打开发布页及已验证的对应安装包链接；开发源码由维护者同步，不接受安装器覆盖。

软件更新会读取 Windows 当前用户已开启的手动系统代理（例如 FlClash 的“系统代理”）；也可以使用 VPN 的虚拟网卡模式。无需给更新器填写 KEY，也不会借用模型平台代理。只开启浏览器代理扩展不能保证软件联网。系统代理配置不含用户名或密码时可直接使用；需认证的代理请先在 VPN 中连接。

GitHub访问失败或更新说明尚未发布时，请稍后重试，也可打开官方下载页，使用官方公布的网盘下载同版本安装包。手工升级请完成或停止任务、退出软件，再运行同通道新版安装包，保持安装器识别的原目录完成覆盖安装。0.26.1/0.27.1 旧更新器未读取系统代理，如果它无法检查更新，请先手动安装0.27.2一次，后续即可使用新版的代理支持。旧版本降级将被阻止，不应以替换 EXE 代替资料恢复。安装失败时保留提示，可从桌面重新启动旧版并查看资料目录 data/updates/install.log；个人资料不会因此删除。

可双击安装目录中的“卸载”（红色垃圾桶图标），或从开始菜单选择“卸载 Aly Image Studio”。系统卸载引擎文件由安装器管理，不需手工改名或删除。卸载默认只删除程序，保留个人资料。重装同通道可继续使用。卸载不会删除外部关联原图或另存为副本。要清理资料请在退出并备份后，手工核对上述应用资料目录；不要删除其他项目数据。

## 常见问题

- 页面打不开：确认有 Edge/Chrome；从快捷方式重开，查看托盘及 data/logs/studio.log。工作台只使用本机地址。
- 资源缺失或被修改：从可信官方安装包覆盖修复。不要清空个人资料，不要用别人的配置或KEY。
- 请求失败：检查所选用途的地址、KEY、模型及渠道能力。网络超时不代表未收费，先核对任务和渠道记录。
- 保存失败：检查磁盘空间和资料目录权限。原图未保存时不要重发生成请求，可按任务状态恢复下载。
- 系统保护拦截：保留提示信息，核对来源和哈希。不要关闭安全防护或添加排除项。

## 外观与参考图

系统设置 → 外观 → 选择主题，可点击默认主题、蓝色之约、月光小憩或云端伙伴即时预览，确定后保存，取消/关闭恢复原主题。页面标题可按主题设置，含标点符号最多12字，五种字体与16–28字号可选；标题始终在顶栏内。
近期缩略图可拖入软件的参考图区域；要复制到桌面或文件夹，可右键近期缩略图选择“复制原图”，然后到目标位置按Ctrl+V，保留原文件名称和画质。图库及放大窗口也提供复制原图。浏览器直接拖到系统文件夹不保证可用，可改用复制原图或另存为。清除近期只隐藏，可用Ctrl+Z逐步撤回。参考原图缺失会明确标红并阻止使用，图库不重复登记已关联原图；设置可清理可重建的缩略图和轻量预览缓存，不删除作品。

## 看图与后台刷新优化

任务列表和图库读取轻量摘要，已有图片结果完整保留，升级后首次启动补建摘要，之后不重复处理大图片结果。前台有图片任务时约每2.5秒刷新，无活动时约10秒，后台约30秒；回到前台立即补查。请求完成后再安排下次，避免堆积。切图释放旧预览加载，缩放和平移按屏幕帧合并绘制；原图、参考图及导出质量保持。首次预览仍可能需要生成缓存，具体流畅度取决于图片、设备和浏览器。
