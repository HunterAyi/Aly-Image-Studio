# Aly Image Studio v0.28.0 版本与验证说明

程序 0.28.0，安装修订 0.28.0.1，stable。Windows 10 22H2 / Windows 11 x64。作者 ayi，官方入口 https://www.aly18.com 。

## 本次功能

工作台当前参数直接显示、悬停展开点选、比例图形网格；参考图按住拖动排序及清晰插入标记。默认浅色清爽白蓝、深色深空石墨；系统设置集中“字体与框体”“工作台与参数”两个可收起调节器，当前窗口原比例预览，支持保存、撤销及恢复默认。自定义主题可调，背景、明暗及透明度保留；左右切图箭头透明。

生成缩略图左上显示提交生成的时刻，详情保留完成时间和耗时。新上传的主页参考图、图库上传后选为参考的图片加入近期，显示原上传时间；参考图片预览仅展示已知参数，不伪造生成任务，隐藏、清除与逐步撤回不删原图。

连接配置卡片隐藏 KEY，仅显示名称与配置状态。Nano Banana 2、Pro、2.1 和渠道后缀识别、协议编号及自动配置推荐编号；成功拉取用本次完整结果替换该 KEY 的旧模型列表，仍存在模型的手动配置保持。AI 对话与聊天连接设置暂未开放，既有资料保留。
