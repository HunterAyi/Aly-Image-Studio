# Aly Image Studio v0.27.3 版本与验证说明

程序0.27.3，安装修订0.27.3.1，正式stable通道；目标 Windows 10 22H2 / Windows 11 x64。作者 ayi，官方入口 https://www.aly18.com 。

## 更新内容

主预览和放大窗口先显示缩略图、最长边1600px轻量预览，进一步放大读取原图；本地会话认证和原文件有效性验证后支持304重验证，关闭窗口释放大图引用。预览缓存与缩略图共用可清理缓存目录，原文件、参考图和导出画质保持。首次建立预览仍需解码原图，本机验收不代表任意低配电脑帧率承诺。

质量缺省时选当前模型支持的最高档，保留已有显式选择。预览增加原文件大小M。近期缩略图、图库和放大窗口增加“复制原图”，通过Windows文件剪贴板提供真实文件，用户到桌面/文件夹按Ctrl+V；软件内拖到参考区保持，直接从浏览器拖到系统文件夹不保证支持。

仅内置生图请求地址改为 https://img.aly18.com，聊天和其他平台连接保持。新配置默认超时500秒，旧配置保留已有值，可修改并保存；高级数值验证和保存失败反馈改善，只修改配置不会重写已保存的加密KEY。
