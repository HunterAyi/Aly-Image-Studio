程序0.27.4，安装修订0.27.4.1，正式stable通道。目标 Windows 10 22H2 / Windows 11 x64。作者 ayi，官方入口 https://www.aly18.com 。

## 本次修复

图片下载兼容VPN虚拟DNS及Windows已启用的手动系统代理。仅遇到198.18/15虚拟地址时通过Cloudflare HTTPS DNS获取真实公网地址；只发送域名，不发送作品路径、签名链接或模型KEY。固定已验证的公网IP，并按原域名验证HTTPS证书；真正内网、混合内网地址和不安全跳转仍拒绝。生成及聊天POST不自动重试，图片下载不会转发模型KEY。

已有生成结果但保存失败的任务可在升级后点击“仅重试下载”，不会再次提交收费生成。链接仍需有效；失效时应向上游请求原结果或新链接，不保证修复后能恢复所有过期图片。

新版正常启动并核对本机身份和资源后，按可信完整文件清单清理未修改的旧官方程序；用户新增/修改文件、未知目录、链接目录、与个人资料重叠目录和被占用程序保留。KEY、设置、历史、草稿及作品保持。旧0.27.2.1和0.27.3.1文件清单已纳入，新版采用签名安装清单供后续升级核对。

后续更新缓存和安装临时文件优先原安装盘；显示安装包大小和保守估计的临时空间，下载及安装前检查剩余空间，校验通过的同包可复用。旧客户端发起本次升级仍使用旧缓存，新版启动后清理可确认的旧安装包。完整更新期间暂时保留新旧程序，不删除浏览器下载文件夹中的ZIP或安装包。
