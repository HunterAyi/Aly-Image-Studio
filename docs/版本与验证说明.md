# v0.27.2 正式首发与验证说明

应用版本 **0.27.2**，安装修订 **0.27.2.1**，正式 stable 通道。目标 Windows 10 22H2 / Windows 11 x64。作者 ayi，官方入口 https://www.aly18.com 。

这是首个面向公众分发的正式版本；此前预发布测试版本的下载记录已整理移除，后续版本以此为更新基线。

## 已完成的验证

- 621 项源码测试、本机实际编译负载与运行组件检查、1486 文件分发清洁审计、必要第三方许可及组件替换检查通过。
- 实际编译程序的桌面快捷方式创建、原图文件操作、原安装目录升级、正常退出与安装重启、资料保留及明确卸载入口已验证。
- 软件更新实际通过 Windows 手动系统代理访问官方 GitHub API 与下载节点，完整下载安装器并通过签名、长度和 SHA256 校验，再由软件确认安装到原目录。
- 独立旧测试版连接修复及实际升级至 v0.27.2 的本机完整流程通过；作者随后确认另一台电脑测试成功。这不代表所有 Windows 和网络条件都已覆盖。
- 最终程序及安装包的本机 Defender 扫描完成，未发现威胁；对应的扫描文件哈希保持一致。

使用模拟模型、合成图片和测试凭证完成工程验收，未进行收费模型调用。测试通过不能保证所有服务商或未知型号的能力。

## 适用范围

其他 Windows 完整环境矩阵、系统外部原图拖放和公网 SmartScreen 体验未完成完整验证。软件没有 Windows 可信代码签名，Defender 的本机无威胁结果不能消除下载信誉或未知发布者提示。

GitHub 国内连接取决于网络，系统代理下通过不代表国内直连可用。网盘手动分发由作者安排，目前没有国内自动更新镜像。版本检测仅接受本仓库的正式发布及官方签名更新信息，下载后由用户确认安装。

新安装为空 KEY 和历史，不包含作者资料；更新和默认卸载保留用户 KEY、设置、历史、草稿与作品。第三方保留原许可及修改/替换权利，完整原始许可位于安装目录 licenses；四字体原文件和 OFL 位于 static/fonts。FFmpeg/dav1d 精确源码随安装，其余[第三方对应源码](https://github.com/HunterAyi/Aly-Image-Studio/releases/download/v0.27.2/Third-Party-Sources.zip)随本首发版提供。
