## 本次更新

- 大图结果保存减少重复读取和处理，合并末张图片的完成提交，保留原图、可靠保存、逐图进度和中断后仅恢复下载的能力。
- 自由模式识别提示词中的明确分辨率和比例，例如“输出4K，比例4:3”，按当前模型支持的能力转换为请求参数，提示词原样发送。参数区显示识别结果；冲突或不支持时提交前提示，不自动降低尺寸。没有明确要求则使用模型默认，手动模式以界面选择为准。识别使用本机规则，不额外调用AI。
- 增加本机响应分段计时，区分等待响应、接收、解析和保存；不上传诊断，不自动重试收费生成。保持已确认的工作台布局、主题、调节器及聊天入口暂未开放状态。

本机离线约21.5MB合成PNG对照中，完整结果收到后本地处理的中位数从3.490秒降至2.138秒。该结果仅为本机合成数据，不代表所有电脑或总生成耗时提升同样比例。上游生成、返回内容大小和网络传输仍会影响总耗时，本版不宣称消除软件与上游全部时间差，也不宣称修复上游502或额外响应内容问题。
