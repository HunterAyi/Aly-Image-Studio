# Aly Image Studio 隐私说明

版本：0.26.1。作者：ayi。官方入口：https://www.aly18.com

本软件在本机运行，通过本机浏览器使用，无需注册软件账号。默认只监听 127.0.0.1，不公开到局域网或互联网。软件不内置统计上报、作品上传或遥测服务。

正式版启动后及运行期间约每6小时检查GitHub官方发布仓库的新版本；系统设置也可手动检查。检查只请求公开版本信息和更新说明，不发送KEY、提示词、聊天、作品或个人资料。GitHub及其下载服务可收到正常网络请求信息，例如IP地址和软件版本。下载安装包及确认安装由用户主动点击；更新文件和安装日志暂存在本机资料目录 data/updates，成功后清理下载的安装器。没有可用的已签名更新说明时不会安装。访问官方发布页或网盘链接交由浏览器进行，适用对应网站的隐私政策。

开发版仅在你手动点击时检查正式版本，不自动下载安装；可打开通过官方签名校验的下载链接，检查同样不发送个人资料。

KEY、平台配置、提示词、聊天、附件、任务、图片、设置及授权目录记录保存在本机当前用户资料目录。Windows 保存 KEY 使用当前用户 DPAPI 加密，不等于整份资料已加密；获得当前 Windows 用户权限的程序仍可能访问资料，请保护系统账号和备份。软件不将完整 KEY 交给网页或写入浏览器存储、常规日志和图片下载请求。

点击模型拉取、连接验证、生成或发送聊天后，相应请求会发送到你选定的平台/中转站；所选模型、提示词、附件及必要上下文可能随请求发送，KEY 用于相应平台认证。请自行核对该服务的隐私、费用和保留政策。点击外部链接会交由浏览器访问对应网站。

本机解析 PDF、文档或视频抽帧不单独上传；发送聊天时，选定内容按模型协议提交。普通视频抽帧不包含声音。图片另存为只复制到通过本机选择器授权的位置。图库关联的外部原图保留原位置；解除关联不会删除原图。

卸载默认保留个人资料；重新安装同一通道可继续使用。测试版和正式版使用不同资料目录。原开发项目 data/output 不自动迁移。备份或手工删除资料前，请退出软件并确认范围，外部关联文件及已另存为副本独立存在。

问题反馈页：https://github.com/HunterAyi/Aly-Image-Studio/issues 。提交反馈时，内容将发送到 GitHub；公开问题及附件可能被他人查看，请先遮盖个人信息。请勿发送 KEY、个人聊天、附件、个人作品或未脱敏的数据库。软件不会自动替你提交反馈。
